# Разработка защищенной информационной системы начисления стипендий с имитацией электронной подписи ведомостей 

Курсовая работа по дисциплине «Программирование». C++17, CMake, Qt 5/6 Widgets (для окна).

## Сборка

Нужны: компилятор C++17 и CMake ≥ 3.16. Для графической версии дополнительно Qt (Widgets).

&#x20;   cmake -B build
    cmake --build build


Цели сборки:

* `scholarship`      - графическое приложение (если Qt найден);
* `scholarship\_cli`  - консольная версия (резервная, Qt не нужен).

Если CMake не находит Qt, укажите путь: `cmake -B build -DCMAKE\_PREFIX\_PATH=<путь к Qt>`.
Windows (MinGW): откройте `CMakeLists.txt` в Qt Creator и выберите комплект Qt.
Для переноса на другой компьютер: `windeployqt scholarship.exe`.

## Запуск

Программа создаёт файлы данных в текущем каталоге (нужны права на запись).
Первый запуск предлагает создать логин и пароль.

## Файлы данных

* `students.bin`  - исходный файл записей (бинарный, запись фиксированного размера);
* `statement.bin` - ведомость (второй файл);
* `statement.sig` - подпись ведомости (имитация ЭП: FNV-1a + учебный RSA, n = 60491);
* `users.bin`     - логин и хеш пароля (пароль в открытом виде не хранится).

## Модули

* `student`    - структура записи, проверки полей, расчёт стипендии;
* `storage`    - чтение и запись записей по позиции, безопасная замена файла;
* `ops`        - добавление, поиск, удаление, пересчёт, упаковка (без вспомогательного массива);
* `sortfilter` - сортировка и фильтрация (контейнер `std::vector`);
* `crypto`     - хеш FNV-1a, модульное возведение в степень, учебный RSA;
* `statement`  - формирование, подпись и проверка ведомости;
* `auth`       - первичная настройка и проверка учётной записи;
* `common.h`   - исключение `FileError`, имена файлов;
* `gui\_\*`, `login\_dialog`, `student\_dialog`, `main\_window` - окно на Qt;
* `main.cpp`, `ui.cpp` - консольная версия.

Ограничения учебной версии: 16-битный модуль RSA и 32-битный хеш не обеспечивают реальной
стойкости. Для настоящей системы нужны SHA-256/ГОСТ Р 34.11-2012 и RSA-2048/ГОСТ Р 34.10-2012.
